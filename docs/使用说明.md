# box4 共享版 v6.4 · 使用说明

## 这是什么
- Magisk / KernelSU / APatch 模块：手机（含热点里连着的设备）流量走你自己的机场，国内站点照常直连。
- 内核 mihomo（arm64）+ 面板 MetaCubeXD + 自带设置页。**不含任何节点**。

## 三步上手
1. 刷入 `box4-共享版-v6.4-*.zip`，重启手机。
2. 打开浏览器 **http://127.0.0.1:7895**（手机本机；同一 WiFi 下用 `http://手机IP:7895`）。
3. 粘贴 Clash / mihomo 订阅链接 → 「保存并应用」，几秒后节点数会出来。

> 模块卡片上不再有「执行」按钮（已删掉 `action.sh`），要看状态开 `http://127.0.0.1:7895`，或 `sh /data/adb/box/box`。

页面里还有：开启 / 彻底关闭、四个接口（移动数据 / WiFi / 热点 / USB）的独立开关（默认全开）。不再有音量键开关，全部在网页里点。

## 命令行（同一个 `box`）
    sh /data/adb/box/box             看状态（开关在网页点按钮）
    sh /data/adb/box/box on          开启
    sh /data/adb/box/box off         彻底关闭（内核/规则/看门狗全停，开机不自启）
    sh /data/adb/box/box sub         按 sub.txt 里的那行链接应用订阅
    sh /data/adb/box/box sub "https://..."   直接给链接
    sh /data/adb/box/box status      看状态
    sh /data/adb/box/box iface hotspot on|off   接口开关（mobile/wifi/hotspot/usb）
    sh /data/adb/box/box webui on|off            设置页起停

## 目录（装完就这些，没有散落脚本）
    /data/adb/box/box            唯一入口
    /data/adb/box/sub.txt        订阅链接（一行）
    /data/adb/box/scripts/       上游基线脚本 + tproxy.conf
    /data/adb/box/webroot/       设置页（index.html + cgi-bin/api）
    /data/adb/box/mihomo/        内核配置、面板、Geo 数据
    /data/adb/box/run/           状态与日志
    /data/adb/modules/box4/      模块本体（只有 module.prop / uninstall.sh / 说明）
    /data/adb/service.d/         开机、看门狗、设置页 三个脚本

## 能调什么
- 接口开关、TUN/TPROXY/REDIRECT、MAC 过滤、绕 CN IP：都在 `/data/adb/box/scripts/tproxy.conf`，改完 `sh box off && sh box on`。
- 面板：`http://127.0.0.1:9090/ui`；分组 `🚀 自动`（延迟自动挑）、`🎯 选择`（手动指定）。

## 常见问题
- **刷完上不了网**：订阅没填，模块故意不自启；去 7895 填链接。
- **设置页打不开**：`sh /data/adb/box/box webui on`，或看 `pidof busybox`。
- **节点数 0**：链接不可用或不是 yaml 订阅（`vless://` 纯文本不支持）。
- **重启后 WiFi 图标显示「无网络」**：v6.3 及更早的已知问题，v6.4 看门狗会自动补回策略路由；如仍出现，执行 `sh /data/adb/box/box off && sh /data/adb/box/box on`。
- **卸载**：管理器卸载后 `rm -rf /data/adb/box`，重启一次即可（新基线自己会清规则）。
